```
git push
```
তারপর ১–২ মিনিট অপেক্ষা করে এই লিংকে দেখো: https://rsraju6734.github.io/shikbolab/science_lab/

ভুল হলে আগের অবস্থায় ফেরা: `git log --oneline` দিয়ে আগের কমিটের নাম দেখে `git revert <কমিটের কোড>` তারপর `git push`।

## ২. নতুন ফাইল কোথায় যাবে
| ফাইল | কোথায় | কেন |
|---|---|---|
| `sitemap.xml` | `science_lab/` (যেমন আছে) | Google Search Console এ জমা দিলে গুগল পেজ খুঁজে পাবে |
| `deploy/404.html` | **`shikbolab/` রিপোর রুটে** (`science_lab` এর বাইরে, একধাপ ওপরে) কপি করো | ভুল লিংকে সুন্দর "পেজ পাওয়া যায়নি" দেখাবে। GitHub Pages শুধু রুটের 404.html চেনে |
| `backend/` ফোল্ডার | যেমন আছে | এখন শুধু নকশা। পরে Supabase এ লাগবে |

> `robots.txt` বানাইনি: GitHub Pages এর "project site" এ সেটা শুধু রুটে কাজ করে, `science_lab` ফোল্ডারে কাজ করে না। অ্যাডমিন পেজে `noindex` ট্যাগ দেওয়া আছে, তাই গুগল সেটা তালিকায় রাখবে না।

## ৩. প্রতি সপ্তাহের রুটিন (৫ মিনিট)
1. অ্যাডমিন → **💾 ব্যাকআপ ও সেটিংস** → **ব্যাকআপ নামাও**। ফাইলটা পেনড্রাইভ/গুগল ড্রাইভে রাখো।
2. **🩺 সিস্টেম চেক** খোলো। কোনো ❌ থাকলে ঠিক করো।
3. **🔗 লিংক চেক** চালাও (সব অধ্যায় খোলে কিনা)।
4. কনটেন্ট বদলালে: **content.js নামাও** → `js/` এ বসাও → push।

## ৬. কাস্টম ডোমেইন (ঐচ্ছিক, পরে)
1. ডোমেইন কেনো (যেমন shikbolab.com, বছরে কয়েক হাজার টাকা)।
2. GitHub রিপো → Settings → Pages → Custom domain এ ডোমেইন লেখো; DNS এ CNAME দাও।
3. "Enforce HTTPS" টিক দাও।
4. ডোমেইন বদলালে `sitemap.xml` এর লিংকগুলোও বদলাতে হবে।
