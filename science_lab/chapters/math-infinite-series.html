📝 সহজ নোট

🎯 এই অধ্যায়ে শিখবে: অনুক্রম ও অসীম ধারা কী, আংশিক সমষ্টি, অসীম গুণোত্তর ধারার সমষ্টি কখন থাকে ও কত, এবং আবৃত্ত দশমিককে সাধারণ ভগ্নাংশে রূপান্তর।

১. অনুক্রম ⭐⭐

  • রাশিগুলো একটি নিয়মে সাজানো থাকলে তাকে অনুক্রম (Sequence) বলে। যেমন 1, 4, 9, 16, … যেখানে n তম পদ = n²।
  • অনুক্রম আসলে একটি ফাংশন: f(n) = n²। n তম পদকে un লেখা হয়। সাধারণ পদ জানলে যেকোনো পদ বের করা যায়।
  • উদাহরণ: 1/2, 1/2², 1/2³, … এর সাধারণ পদ 1/2ⁿ। 3, 1, −1, −3, … এর সাধারণ পদ 5 − 2n। 1, 2/3, 3/5, 4/7, … এর সাধারণ পদ n/(2n − 1)।
  • n যত বড় হয়, কিছু অনুক্রমের পদ একটি মানের দিকে এগোয় (যেমন 1/n → 0), আর কিছু অনুক্রম এগোয় না (যেমন n²)।

২. ধারা ও আংশিক সমষ্টি ⭐⭐⭐

  • অনুক্রমের পদগুলো + চিহ্নে যুক্ত করলে ধারা (Series) হয়: u₁ + u₂ + u₃ + … + uₙ + …
  • পদসংখ্যা সসীম হলে সসীম ধারা, অসীম হলে অসীম ধারা।
  • n তম আংশিক সমষ্টি Sₙ = u₁ + u₂ + … + uₙ (প্রথম n টি পদের সমষ্টি)। S₁ = u₁, S₂ = u₁ + u₂ ইত্যাদি।
  • n বাড়ালে Sₙ যদি একটি নির্দিষ্ট সংখ্যার দিকে এগোয়, তাহলে ধারার সমষ্টি আছে। না এগোলে সমষ্টি নেই।
  • উদাহরণ ১: 1 + 2 + 3 + … এ Sₙ = n(n+1)/2, n বাড়লে Sₙ অসীম বড় হয় ⇒ সমষ্টি নেই। আর 1 − 1 + 1 − 1 + … এ Sₙ একবার 1, একবার 0 ⇒ সমষ্টি নেই।

৩. অসীম গুণোত্তর ধারা ⭐⭐⭐

a + ar + ar² + ar³ + … (প্রথম পদ a, সাধারণ অনুপাত r)
  • n তম পদ = arⁿ⁻¹। প্রথম n পদের সমষ্টি: r < 1 হলে Sₙ = a(1 − rⁿ)/(1 − r), r > 1 হলে Sₙ = a(rⁿ − 1)/(r − 1)।
  • |r| < 1 হলে (−1 < r < 1): n বাড়লে rⁿ → 0, তাই Sₙ → a/(1 − r)। অসীমতক সমষ্টি S∞ = a / (1 − r)।
  • |r| > 1 হলে: |rⁿ| অসীম বড় হয়, তাই সমষ্টি নেই।
  • r = −1: ধারা a − a + a − a …, Sₙ একবার a একবার 0 ⇒ সমষ্টি নেই।
  • r = 1: ধারা a + a + a + …, Sₙ = na অসীম বড় হয় ⇒ সমষ্টি নেই।
  • সারকথা: সমষ্টি আছে কেবল −1 < r < 1 হলে এবং তখন S = a/(1 − r)।
⚠️ সাধারণ ভুল: ① r = 1 বা |r| ≥ 1 হলেও a/(1−r) বসিয়ে দেওয়া। ② সাধারণ অনুপাত r বের করতে দ্বিতীয় পদ ÷ প্রথম পদ না করে উল্টো করা। ③ n তম পদ arⁿ⁻¹, arⁿ নয়।

৪. আবৃত্ত (পৌনঃপুনিক) দশমিককে ভগ্নাংশে ⭐⭐⭐

  • আবৃত্ত অংশকে অসীম গুণোত্তর ধারা বানাও, তারপর S = a/(1 − r)।
  • 0.5̇ = 0.5 + 0.05 + 0.005 + … এখানে a = 0.5, r = 0.1 ⇒ S = 0.5/0.9 = 5/9।
  • 0.1̇2̇ = 0.12 + 0.0012 + … এখানে a = 0.12, r = 0.01 ⇒ S = 0.12/0.99 = 4/33।
  • 1.231̇ (231 আবৃত্ত) = 1 + (0.231 + 0.000231 + …) এখানে a = 0.231, r = 0.001 ⇒ 1 + 0.231/0.999 = 1 + 231/999 = 410/333।
  • সূত্র: আবৃত্ত অংশে m টি অঙ্ক হলে r = 1/10ᵐ।

৫. x এর উপর শর্ত (উদাহরণ ৮) ⭐⭐

  • ধারা 1/(2x+1) + 1/(2x+1)² + 1/(2x+1)³ + …: প্রথম পদ a = 1/(2x+1) এবং r = 1/(2x+1)।
  • সমষ্টি থাকতে |1/(2x+1)| < 1 ⇒ |2x + 1| > 1 ⇒ x > 0 অথবা x < −1।
  • তখন S∞ = a/(1 − r) = 1/(2x)।

🪜 ধাপে ধাপে

👉 "পরের ধাপ" চাপতে থাকো।
১) S∞ = a/(1 − r) কেন?
ধাপ ১: Sₙ = a + ar + … + arⁿ⁻¹। দুই পক্ষকে r দিয়ে গুণ করলে r·Sₙ = ar + ar² + … + arⁿ।
ধাপ ২: বিয়োগ করলে Sₙ − r·Sₙ = a − arⁿ, অর্থাৎ Sₙ(1 − r) = a(1 − rⁿ)। তাই Sₙ = a(1 − rⁿ)/(1 − r) (r ≠ 1)।
ধাপ ৩: যদি |r| < 1 হয়, n অনেক বড় করলে rⁿ প্রায় 0 হয় (যেমন (0.5)²⁰ ≈ 0.000001)।
ধাপ ৪: তখন Sₙ প্রায় a(1 − 0)/(1 − r) = a/(1 − r) ✔। এটাই অসীমতক সমষ্টি S∞।
২) 1/3 + 1/3² + 1/3³ + … (বই উদাহরণ ২ক)
ধাপ ১: প্রথম পদ a = 1/3। দ্বিতীয় পদ 1/9।
ধাপ ২: r = (1/9) ÷ (1/3) = 1/3। |r| = 1/3 < 1 ⇒ সমষ্টি আছে।
ধাপ ৩: S∞ = a/(1 − r) = (1/3)/(1 − 1/3) = (1/3)/(2/3) = 1/2।
ধাপ ৪: যাচাই: 1/3 + 1/9 + 1/27 + 1/81 = 0.333 + 0.111 + 0.037 + 0.0123 ≈ 0.494। 0.5 এর খুব কাছে ✔।
৩) 1.231̇ (আবৃত্ত 231) কে ভগ্নাংশে (বই উদাহরণ ৩গ)
ধাপ ১: 1.231231231… = 1 + (0.231 + 0.000231 + 0.000000231 + …)।
ধাপ ২: বন্ধনীর ভেতরে অসীম গুণোত্তর ধারা: a = 0.231, r = 0.000231/0.231 = 0.001।
ধাপ ৩: S = 0.231/(1 − 0.001) = 0.231/0.999 = 231/999 (উপরে-নিচে 1000 গুণ)।
ধাপ ৪: 231/999 কে সংক্ষেপ করি (উভয়কে 3 দিয়ে ভাগ): 77/333।
ধাপ ৫: মোট = 1 + 77/333 = 410/333 ✔। যাচাই: 410 ÷ 333 = 1.231231… ✔।
৪) 1/(2x+1) + 1/(2x+1)² + … (বই উদাহরণ ৮): x = 3/2 হলে পঞ্চম পদ ও প্রথম ১০ পদের সমষ্টি
ধাপ ১: x = 3/2 হলে 2x + 1 = 4। ধারা 1/4 + 1/4² + 1/4³ + …। a = 1/4, r = 1/4।
ধাপ ২: পঞ্চম পদ = ar⁴ = (1/4)·(1/4)⁴ = 1/4⁵ = 1/1024।
ধাপ ৩: S₁₀ = a(1 − r¹⁰)/(1 − r) = (1/4)(1 − 1/4¹⁰)/(3/4) = (1/3)(1 − 1/4¹⁰)।
ধাপ ৪: 4¹⁰ = 1048576। S₁₀ = (1/3)(1 − 0.00000095) ≈ 0.33333। অসীমতক সমষ্টি 1/3 এর খুব কাছে ✔।
৫) তিন পদের সমষ্টি 24⅘ ও গুণফল 64 (অনুশীলনী ৭ এর ১০): সাধারণ অনুপাত 1/5 হলে অসীমতক সমষ্টি
ধাপ ১: তিন ক্রমিক পদ a/r, a, ar। গুণফল = a³ = 64 ⇒ a = 4 (মাঝের পদ)।
ধাপ ২: সমষ্টি 4/r + 4 + 4r = 124/5 ⇒ 4(r + 1/r) = 124/5 − 4 = 104/5 ⇒ r + 1/r = 26/5।
ধাপ ৩: 5r² − 26r + 5 = 0 ⇒ (5r − 1)(r − 5) = 0 ⇒ r = 1/5 বা r = 5।
ধাপ ৪: r = 1/5 হলে তিন পদ 20, 4, 4/5 (যোগফল 24.8 ✔, গুণফল 20 × 4 × 0.8 = 64 ✔)। প্রথম পদ 20।
ধাপ ৫: S∞ = 20/(1 − 1/5) = 20/(4/5) = 25 ✔।

🔢 ল্যাব ১: অনুক্রম ও সীমা

👉 অনুক্রম বেছে নাও। n যত বাড়ে পদগুলো কোথায় যায় দেখো। ε স্লাইডার দিয়ে দেখো, কত তম পদের পর সব পদ সীমার ε এর মধ্যে থাকে (বই অনুশীলনী ৭ এর ৫ নং প্রশ্নের মতো)।

📊 ল্যাব ২: গুণোত্তর ধারার আংশিক সমষ্টি

👉 a ও r বদলাও। প্রতিটি বিন্দু একটি আংশিক সমষ্টি Sₙ। |r| < 1 হলে বিন্দুগুলো একটি সবুজ রেখার (S∞) দিকে এগোবে। |r| ≥ 1 হলে এগোবে না, বাড়তে বা লাফাতে থাকবে।

🔁 ল্যাব ৩: আবৃত্ত দশমিক থেকে ভগ্নাংশ

👉 পূর্ণ অংশ, আবৃত্ত-না-হওয়া অংশ ও আবৃত্ত অংশ (বইয়ের মতো বন্ধনীর ভেতরের অঙ্ক) লেখো। ল্যাব অসীম গুণোত্তর ধারা বানিয়ে ভগ্নাংশ বের করবে এবং ভাগ করে মিলিয়ে দেখাবে। বইয়ের তিনটি উদাহরণ নিচের বাটনে আছে।

🎚️ ল্যাব ৪: x এর কোন মানে সমষ্টি আছে? (উদাহরণ ৮)

👉 ধারা: 1/(2x+1) + 1/(2x+1)² + 1/(2x+1)³ + …। x টেনে দেখো। সবুজ অংশে (x > 0 বা x < −1) সমষ্টি আছে এবং সমান 1/(2x)। লাল অংশে নেই।
