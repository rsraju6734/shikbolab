📝 নোট🪜 ধাপে ধাপে🔺 প্যাসকেল ত্রিভুজ🧩 বিস্তৃতি🎯 আসন্ন মান🔎 নির্দিষ্ট পদ⚖️ কোনটি বড়✍️ প্র্যাকটিস❓ কুইজ📖 প্রশ্নোত্তর

📝 সহজ নোট

🎯 এই অধ্যায়ে শিখবে: দ্বিপদী রাশির ঘাত (শক্তি) সহজে বিস্তৃত করা, প্যাসকেলের ত্রিভুজ, n! ও ⁿCᵣ, সাধারণ পদ এবং নির্দিষ্ট পদ বা সহগ নির্ণয়। (বইয়ে n অ-ঋণাত্মক পূর্ণসংখ্যা)

১. দ্বিপদী রাশি ও (1 + y)ⁿ এর বিস্তৃতি ⭐⭐

  • দুই পদের যোগ বা বিয়োগে গঠিত রাশিকে দ্বিপদী রাশি বলে। যেমন a + b, x − y, 1 + x।
  • (1 + y) কে বারবার গুণ করে পাই: (1 + y)² = 1 + 2y + y², (1 + y)³ = 1 + 3y + 3y² + y³ ইত্যাদি।
  • লক্ষণ: (1 + y)ⁿ এর বিস্তৃতিতে (n + 1) টি পদ থাকে। y এর ঘাত 0 থেকে শুরু হয়ে 1, 2, … n পর্যন্ত বাড়ে।
  • প্রতি y এর ঘাতের সহগকে দ্বিপদী সহগ বলে।

২. প্যাসকেলের ত্রিভুজ ⭐⭐⭐

  • সহগগুলো সাজালে একটি ত্রিভুজ তৈরি হয়: n = 0: 1; n = 1: 1 1; n = 2: 1 2 1; n = 3: 1 3 3 1; n = 4: 1 4 6 4 1; n = 5: 1 5 10 10 5 1।
  • দুই পাশে সবসময় 1। ভেতরের প্রতিটি সংখ্যা = উপরের দুটি সংখ্যার যোগফল। যেমন 10 = 4 + 6।
  • বুঝে নাও: (1 + y)⁵ = 1 + 5y + 10y² + 10y³ + 5y⁴ + y⁵ এবং (1 + y)⁶ = 1 + 6y + 15y² + 20y³ + 15y⁴ + 6y⁵ + y⁶।
  • সীমাবদ্ধতা: বড় n এর জন্য আগের সব সারি লিখতে হয়, তাই সরাসরি সূত্র দরকার।

৩. n! (ফ্যাক্টোরিয়াল) ও ⁿCᵣ ⭐⭐⭐

  • n! = n(n − 1)(n − 2) ··· 3·2·1। যেমন 5! = 120। এবং 0! = 1।
  • ⁿCᵣ = n! / (r!(n − r)!)। এটাকে (n r) চিহ্নেও লেখা হয়।
  • সহজ উপায়: ⁿCᵣ = [n(n − 1)(n − 2) ··· (n − r + 1)] / (1·2·3 ··· r)। যেমন ⁴C₂ = (4 × 3)/(1 × 2) = 6।
  • ⁿC₀ = ⁿCₙ = 1, ⁿC₁ = n এবং ⁿCᵣ = ⁿCn−r (প্যাসকেলের ত্রিভুজের প্রতিসমতা)। ⁿCᵣ = ⁿ⁻¹Cr−1 + ⁿ⁻¹Cᵣ (উপরের দুটির যোগ)।

৪. (1 + y)ⁿ এর সূত্র ⭐⭐⭐

(1 + y)ⁿ = 1 + ny + n(n − 1)/(1·2) · y² + n(n − 1)(n − 2)/(1·2·3) · y³ + … + yⁿ

সাধারণ পদ বা (r + 1) তম পদ: Tr+1 = ⁿCᵣ yʳ।

উদাহরণ: (1 + 3x)⁵ এ y = 3x বসিয়ে = 1 + 15x + 90x² + 270x³ + 405x⁴ + 243x⁵। আর (1 − 3x)⁵ এ শুধু সহগের চিহ্ন একান্তর (+, −, +, …) হয়: 1 − 15x + 90x² − 270x³ + 405x⁴ − 243x⁵।

৫. (x + y)ⁿ এর বিস্তৃতি ⭐⭐⭐

(x + y)ⁿ = xⁿ + ⁿC₁ xⁿ⁻¹y + ⁿC₂ xⁿ⁻²y² + ⁿC₃ xⁿ⁻³y³ + … + yⁿ

  • প্রতি পদে x ও y এর ঘাতের যোগফল n। x এর ঘাত n থেকে 0 পর্যন্ত কমে, y এর ঘাত 0 থেকে n পর্যন্ত বাড়ে।
  • সাধারণ পদ (r + 1) তম পদ: Tr+1 = ⁿCᵣ · xⁿ⁻ʳ · yʳ।
  • মধ্যপদ: n জোড় হলে একটিই মধ্যপদ, (n/2 + 1) তম পদ। n বিজোড় হলে দুটি মধ্যপদ।
  • পদের ভেতরে ঋণাত্মক বা ভগ্নাংশ থাকলে বন্ধনীসহ বসাও। যেমন (x − 1/x²)⁵ এ y = (−1/x²)।

৬. নির্দিষ্ট পদ বা সহগ খোঁজার কৌশল ⭐⭐⭐

  1. (r + 1) তম পদ লেখো: ⁿCᵣ (প্রথম পদ)ⁿ⁻ʳ (দ্বিতীয় পদ)ʳ।
  2. x এর ঘাত r এর মাধ্যমে বের করো। যেমন (x + 1/x²)⁶ এ ঘাত = (6 − r) − 2r = 6 − 3r।
  3. ঘাতকে প্রয়োজনীয় মানের সমান করে r বের করো। x মুক্ত পদ মানে ঘাত = 0 ⇒ 6 − 3r = 0 ⇒ r = 2।
  4. r একটি পূর্ণসংখ্যা এবং 0 ≤ r ≤ n হতে হবে। নইলে ওই পদ নেই (সহগ 0)।
  5. r দিয়ে সহগ হিসাব করো: T₃ = ⁶C₂ = 15।

৭. আসন্ন মান নির্ণয় ⭐⭐

  • (1.01)⁸ = (1 + 0.01)⁸ = 1 + 8(0.01) + 28(0.01)² + 56(0.01)³ + … ≈ 1.0829। ছোটো y হলে প্রথম কয়েকটি পদই যথেষ্ট, কারণ y², y³ খুব ছোটো হয়ে যায়।
  • (1.995)⁷ = (2 − 0.005)⁷। এখানে (2 − x/2)⁷ এর x = 0.01 বসিয়ে বইয়ের উত্তর 125.7767।

🪜 ধাপে ধাপে

👉 "পরের ধাপ" চাপতে থাকো। প্রতিটি ধাপ নিজে খাতায় করে মেলাও।
১) (1 + 3x)⁵ কে বিস্তৃত করো (বই উদাহরণ ১)
ধাপ ১: n = 5। প্যাসকেলের ত্রিভুজের ৫ম সারি: 1, 5, 10, 10, 5, 1।
ধাপ ২: (1 + y)⁵ = 1 + 5y + 10y² + 10y³ + 5y⁴ + y⁵ তে y = 3x বসাই।
ধাপ ৩: 1 + 5(3x) + 10(3x)² + 10(3x)³ + 5(3x)⁴ + (3x)⁵।
ধাপ ৪: (3x)² = 9x², (3x)³ = 27x³, (3x)⁴ = 81x⁴, (3x)⁵ = 243x⁵ ⇒ 1 + 15x + 90x² + 270x³ + 405x⁴ + 243x⁵ ✔।
ধাপ ৫: (1 − 3x)⁵ এর জন্য শুধু চিহ্ন একান্তর: 1 − 15x + 90x² − 270x³ + 405x⁴ − 243x⁵।
২) (1 + 2/x)⁸ এর প্রথম ৫ পদ (বই উদাহরণ ৩)
ধাপ ১: y = 2/x। সূত্র: 1 + ⁸C₁y + ⁸C₂y² + ⁸C₃y³ + ⁸C₄y⁴।
ধাপ ২: ⁸C₁ = 8, ⁸C₂ = (8·7)/(1·2) = 28, ⁸C₃ = (8·7·6)/(1·2·3) = 56, ⁸C₄ = (8·7·6·5)/(1·2·3·4) = 70।
ধাপ ৩: 8·(2/x) = 16/x; 28·(4/x²) = 112/x²; 56·(8/x³) = 448/x³; 70·(16/x⁴) = 1120/x⁴।
ধাপ ৪: 1 + 16/x + 112/x² + 448/x³ + 1120/x⁴ + … ✔।
৩) (1 − x²/4)⁸ এর x³ ও x⁶ এর সহগ (বই উদাহরণ ৪)
ধাপ ১: y = −x²/4। বিস্তৃতিতে y এর ঘাত: 1, y, y², y³ …। y এর ঘাত বাড়লে x এর ঘাত 0, 2, 4, 6, … (সব জোড়)।
ধাপ ২: তাই x³ (বিজোড় ঘাত) পদটি নেই। x³ এর সহগ 0।
ধাপ ৩: x⁶ আসে y³ থেকে: ⁸C₃ · (−x²/4)³ = 56 · (−x⁶/64) = −(7/8)x⁶।
ধাপ ৪: x⁶ এর সহগ = −7/8।
৪) (x + 1/x²)⁶ এ x মুক্ত পদ (বই উদাহরণ ৬)
ধাপ ১: (r + 1) তম পদ Tr+1 = ⁶Cᵣ · x6−r · (1/x²)ʳ = ⁶Cᵣ · x6−3r।
ধাপ ২: x মুক্ত পদ মানে x এর ঘাত 0: 6 − 3r = 0 ⇒ r = 2।
ধাপ ৩: r = 2 পূর্ণসংখ্যা এবং 0 ≤ 2 ≤ 6 ✔। তাই T₃ = ⁶C₂ = (6·5)/(1·2) = 15।
ধাপ ৪: যাচাই: প্রথম পদগুলো x⁶ + 6x³ + 15 + 20/x³ + … ✔। (ল্যাব ৪ এ নিজে করো।)
৫) (2 − x/2)⁷ এর প্রথম ৪ পদ এবং (1.995)⁷ (বই উদাহরণ ৭)
ধাপ ১: (x + y)ⁿ সূত্রে x = 2, y = −x/2: 2⁷ + ⁷C₁2⁶(−x/2) + ⁷C₂2⁵(−x/2)² + ⁷C₃2⁴(−x/2)³।
ধাপ ২: 128 + 7·64·(−x/2) + 21·32·(x²/4) + 35·16·(−x³/8) = 128 − 224x + 168x² − 70x³।
ধাপ ৩: 2 − x/2 = 1.995 ⇒ x/2 = 0.005 ⇒ x = 0.01। বসাই: 128 − 2.24 + 0.0168 − 0.00007 ≈ 125.7767।
৬) (k − x/3)⁷ এ k³ এর সহগ 560 হলে x = ? (বই উদাহরণ ১০ খ)
ধাপ ১: k³ হবে যখন k এর ঘাত 7 − r = 3 ⇒ r = 4। চতুর্থের পরের অর্থাৎ পঞ্চম পদ T₅।
ধাপ ২: T₅ = ⁷C₄ · k³ · (−x/3)⁴ = 35 · k³ · x⁴/81।
ধাপ ৩: সহগ 35x⁴/81 = 560 ⇒ x⁴ = 560 × 81/35 = 16 × 81 = 1296।
ধাপ ৪: x⁴ = 1296 = 6⁴ ⇒ x = 6 (বাস্তব ধনাত্মক মান; −6 ও চলবে)।

🔺 ল্যাব ১: প্যাসকেলের ত্রিভুজ ও ⁿCᵣ

👉 সারি n ও অবস্থান r বদলাও। ত্রিভুজে নির্বাচিত সংখ্যা লাল, তার উপরের দুটি সংখ্যা (যাদের যোগফল সে) সবুজ দেখাবে।

🧩 ল্যাব ২: (a + bx)ⁿ এর পূর্ণ বিস্তৃতি

👉 a, b ও n বদলাও (যেমন a = ১, b = ৩, n = ৫ দিলে উদাহরণ ১)। প্রতিটি পদের সহগ = ⁿCᵣ · aⁿ⁻ʳ · bʳ। নির্বাচিত পদ r হাইলাইট হবে।

🎯 ল্যাব ৩: দ্বিপদী দিয়ে আসন্ন মান (যেমন (1.01)⁸)

👉 (A + δ)ⁿ এর মান প্রথম k টি পদ দিয়ে হিসাব করো এবং আসল মানের সাথে তুলনা করো। δ ছোটো হলে অল্প পদেই প্রায় ঠিক মান পাওয়া যায়।

🔎 ল্যাব ৪: নির্দিষ্ট পদ, সহগ ও x মুক্ত পদ

👉 রাশি (a·xs + b·xt)ⁿ। কোন পদে x এর ঘাত k তা খুঁজে সহগ বের করো। k = ০ দিলে x মুক্ত পদ।

⚖️ ল্যাব ৫: কোনটি বড়? (m−1)ⁿ + mⁿ নাকি (m+1)ⁿ (অনুশীলনী ১৩ এর মতো)

👉 বইয়ে প্রশ্ন: 99⁵⁰ + 100⁵⁰ ও 101⁵⁰ এর কোনটি বড়? এখানে m = ১০০, n = ৫০। দ্বিপদী বিস্তৃতি দিয়ে (100 ± 1)⁵⁰ লেখা যায়। m ও n বদলে নিজে দেখো।

✍️ প্র্যাকটিস (বইয়ের ধাঁচে)

👉 উত্তর পূর্ণসংখ্যা বা দশমিক লিখতে পারো। ঋণাত্মক হলে মাইনাস দাও।
