📈 সূচকীয় ও লগারিদমীয় ফাংশন

📝 নোট🪜 ধাপে ধাপে🧮 সূচক সূত্র√ মূল📈 লেখচিত্র🔢 লগারিদম সূত্র🧭 ডোমেন-রেঞ্জ✍️ প্র্যাকটিস❓ কুইজ📖 প্রশ্নোত্তর

📝 সহজ নোট

🎯 এই অধ্যায়ে শিখবে: সূচকের সূত্র (পূর্ণসংখ্যা ও ভগ্নাংশ সূচক), মূল, লগারিদম ও তার সূত্র, ভিত্তি পরিবর্তন, সূচকীয়-লগারিদমীয়-পরমমান ফাংশনের ডোমেন, রেঞ্জ ও লেখচিত্র।

১. সূচক ও মৌলিক সূত্র ⭐⭐⭐

  • aⁿ = a · a · a … (n বার)। a কে ভিত্তি এবং n কে সূচক বলে। a¹ = a।
  • aᵐ · aⁿ = am+n, (aᵐ)ⁿ = amn, (ab)ⁿ = aⁿbⁿ, (a/b)ⁿ = aⁿ/bⁿ।
  • aᵐ/aⁿ = am−n (m > n হলে) এবং = 1/an−m (m < n হলে)।
  • শূন্য ও ঋণাত্মক সূচক: a⁰ = 1 এবং a−n = 1/aⁿ (a ≠ 0)। কারণ মৌলিক সূত্র aᵐ·aⁿ = am+n সব সূচকে খাটাতে হলে এটাই হতে হয়।
  • এগুলো গাণিতিক আরোহ পদ্ধতিতে প্রমাণ করা যায়।

২. মূল ⭐⭐

  • xⁿ = a হলে x কে a এর একটি n তম মূল বলে। n = 2 হলে বর্গমূল, n = 3 হলে ঘনমূল।
  • a > 0 হলে একটি অনন্য ধনাত্মক n তম মূল আছে, তাকে ⁿ√a লেখে (মুখ্য মূল)। n জোড় হলে −ⁿ√a ও আরেকটি মূল (যেমন 16 এর 4 তম মূল 2 ও −2)।
  • a < 0 এবং n বিজোড় হলে একটি মাত্র মূল আছে: ⁿ√a = −ⁿ√|a| (যেমন ∛(−27) = −3)।
  • a < 0 এবং n জোড় হলে বাস্তব মূল নেই (যেমন −9 এর বর্গমূল নেই)।
  • √(a²) = |a|।
  • সূত্র (a > 0): (ⁿ√a)ᵐ = ⁿ√(aᵐ) এবং ⁿ√a = ⁿᵏ√(aᵏ)। অর্থাৎ m/n = p/q হলে ⁿ√(aᵐ) = q√(aᵖ)।

৩. ভগ্নাংশ সূচক ⭐⭐⭐

  • a1/n = ⁿ√a (a > 0, অথবা a < 0 ও n বিজোড়)।
  • am/n = (a1/n)ᵐ = ⁿ√(aᵐ) (a > 0)।
  • ভগ্নাংশ (মূলদ) সূচকেও সব সূত্র খাটে: aʳ·aˢ = ar+s, aʳ/aˢ = ar−s, (aʳ)ˢ = ars, (ab)ʳ = aʳbʳ।
  • কাজে লাগার তথ্য: (i) aˣ = 1 (a > 0, a ≠ 1) হলে x = 0। (ii) aˣ = aʸ (a > 0, a ≠ 1) হলে x = y। (iii) aˣ = bˣ (x ≠ 0, a/b > 0) হলে a = b।
  • সমীকরণ সমাধানের কৌশল: দুই পক্ষকে একই ভিত্তিতে এনে সূচক সমান করো। জটিল হলে 2ˣ = y ধরে দ্বিঘাত বানাও।

৪. লগারিদম ⭐⭐⭐

  • a > 0, a ≠ 1, b > 0 হলে: aˣ = b ⇔ x = logₐ b। (x কে b এর a ভিত্তিক লগারিদম বলে।)
  • বিপরীতক্রমে b কে a ভিত্তিক x এর প্রতিলগ (antilog) বলে।
  • উদাহরণ: 2⁶ = 64 ⇒ log₂64 = 6। 5⁻² = 1/25 ⇒ log₅(1/25) = −2।
  • শূন্য ও ঋণাত্মক সংখ্যার লগারিদম নির্ণয় করা যায় না (b > 0 লাগবে)।
  • দুটি সরাসরি ফল: logₐ(aˣ) = x এবং a^(logₐ b) = b।
  • সূত্রাবলি: (১) logₐa = 1, logₐ1 = 0 (২) logₐ(MN) = logₐM + logₐN (৩) logₐ(M/N) = logₐM − logₐN (৪) logₐ(Mᴺ) = N·logₐM (৫) ভিত্তি পরিবর্তন: logₐM = log_b M × logₐ b।
  • লক্ষ করো: a > 1, x > 1 হলে logₐx > 0। a > 1, 0 < x < 1 হলে logₐx < 0। (0 < a < 1 হলে উল্টো।)

৫. সূচকীয় ফাংশন f(x) = aˣ ⭐⭐⭐

  • a > 0, a ≠ 1। ডোমেন = (−∞, ∞), রেঞ্জ = (0, ∞)। মান সবসময় ধনাত্মক।
  • লেখচিত্র সবসময় (0, 1) বিন্দু দিয়ে যায় (a⁰ = 1)।
  • a > 1: x বাড়লে y বাড়ে (ঊর্ধ্বগামী)। x → −∞ হলে y → 0।
  • 0 < a < 1: x বাড়লে y কমে (নিম্নগামী)। x → ∞ হলে y → 0।
  • উদাহরণ: y = 2ˣ, y = (1/2)ˣ, y = eˣ (2 < e < 3)।

৬. লগারিদমীয় ফাংশন f(x) = logₐx ⭐⭐⭐

  • সূচকীয় ফাংশন এক-এক ও সার্বিক, তাই বিপরীত ফাংশন আছে: f⁻¹(y) = logₐy। লগারিদমীয় ফাংশন সূচকীয় ফাংশনের বিপরীত।
  • ডোমেন = (0, ∞), রেঞ্জ = (−∞, ∞)। লেখচিত্র (1, 0) দিয়ে যায় (logₐ1 = 0)।
  • a > 1 হলে ঊর্ধ্বগামী, 0 < a < 1 হলে নিম্নগামী। x → 0 হলে y → −∞ (a > 1)।
  • aˣ ও logₐx এর লেখচিত্র y = x রেখার সাপেক্ষে প্রতিসম (বিপরীত ফাংশনের ধর্ম)।
  • ভিত্তি e (≈ 2.718) হলে লেখা হয় ln x। ভিত্তি 10 হলে log₁₀x।

৭. পরমমান ফাংশন ⭐⭐

  • |x| = x (x ≥ 0 হলে), = −x (x < 0 হলে)। যেমন |−3| = 3।
  • y = |x| এর ডোমেন R, রেঞ্জ [0, ∞)। লেখচিত্র "V" আকৃতির, মূলবিন্দুতে কোণ।
  • f(x) = x/|x| এর ডোমেন R − {0}, রেঞ্জ {−1, 1}।

৮. ডোমেন ও রেঞ্জ বের করার কৌশল ⭐⭐

  • লগের ভেতরের রাশি অবশ্যই ধনাত্মক। ln((a+x)/(a−x)) এর জন্য (a+x) ও (a−x) একই চিহ্নের হতে হবে। দেখা যায় ডোমেন = (−a, a)।
  • হর শূন্য হতে পারবে না। যেমন y = (4−x)/(4+x) এর ডোমেন R − {−4}।
  • রেঞ্জ বের করতে x কে y এর মাধ্যমে প্রকাশ করো (বিপরীত বের করো), তারপর y এর কোন মানে x বাস্তব হয় দেখো।

🪜 ধাপে ধাপে

👉 "পরের ধাপ" চাপতে থাকো। প্রতিটি ধাপ নিজে খাতায় করে মেলাও।
১) সূচকীয় সমীকরণ: 4ˣ − 3·2x+2 + 2⁵ = 0 (বই উদাহরণ ১৭)
ধাপ ১: সব ভিত্তি 2 বানাই: (2²)ˣ − 3·2ˣ·2² + 32 = 0 ⇒ (2ˣ)² − 12·2ˣ + 32 = 0।
ধাপ ২: 2ˣ = y ধরি: y² − 12y + 32 = 0।
ধাপ ৩: উৎপাদকে ভাঙি: y² − 4y − 8y + 32 = 0 ⇒ y(y − 4) − 8(y − 4) = 0 ⇒ (y − 4)(y − 8) = 0।
ধাপ ৪: y = 4 বা 8 ⇒ 2ˣ = 2² বা 2³ ⇒ x = 2, 3।
ধাপ ৫: যাচাই: x = 2: 16 − 3·16 + 32 = 0 ✔; x = 3: 64 − 3·32 + 32 = 0 ✔।
২) xx√x = (x√x)ˣ হলে x = ? (বই উদাহরণ ১১)
ধাপ ১: x√x = x · x1/2 = x3/2। তাই ডানপক্ষ = (x3/2)ˣ = (xˣ)3/2।
ধাপ ২: বামপক্ষ xx√x = (xˣ)√x।
ধাপ ৩: (xˣ)√x = (xˣ)3/2। ভিত্তি সমান, তাই সূচক সমান: √x = 3/2।
ধাপ ৪: বর্গ করে x = 9/4 = 2.25।
৩) aˣ = b, bʸ = c, cᶻ = a হলে xyz = 1 (বই উদাহরণ ৯)
ধাপ ১: b = aˣ, c = bʸ, a = cᶻ।
ধাপ ২: b = aˣ = (cᶻ)ˣ = czx = (bʸ)zx = bxyz।
ধাপ ৩: b¹ = bxyz। ভিত্তি সমান (b ≠ 1) ⇒ xyz = 1।
৪) a = 2 + 22/3 + 21/3 হলে a³ − 6a² + 6a − 2 = 0 (বই উদাহরণ ১৬)
ধাপ ১: a − 2 = 22/3 + 21/3। দুই পক্ষের ঘন: (a − 2)³ = (22/3 + 21/3)³।
ধাপ ২: (p + q)³ = p³ + q³ + 3pq(p + q)। এখানে p³ = 4, q³ = 2, pq = 2। তাই ডানপক্ষ = 4 + 2 + 3·2·(a − 2) = 6 + 6(a − 2)।
ধাপ ৩: বামপক্ষ: a³ − 6a² + 12a − 8। সমান করি: a³ − 6a² + 12a − 8 = 6a − 6।
ধাপ ৪: সরল করে a³ − 6a² + 6a − 2 = 0 ✔।
৫) লগারিদমীয় সমীকরণ (বই উদাহরণ ২৩)
ধাপ ১ (ক): log√8x = 3⅓ = 10/3। সংজ্ঞা: x = (√8)10/3।
ধাপ ২: √8 = 23/2। x = 2(3/2)(10/3) = 2⁵ = 32।
ধাপ ৩ (খ): log₁₀[98 + √(x² − 12x + 36)] = 2 ⇒ 98 + √(x² − 12x + 36) = 10² = 100।
ধাপ ৪: √(x² − 12x + 36) = 2 ⇒ x² − 12x + 36 = 4 ⇒ x² − 12x + 32 = 0 ⇒ (x − 4)(x − 8) = 0।
ধাপ ৫: x = 4 বা 8। যাচাই: x = 4: √(16 − 48 + 36) = √4 = 2 ✔; x = 8: √(64 − 96 + 36) = 2 ✔।
৬) প্রমাণ: 1/loga(abc) + 1/logb(abc) + 1/logc(abc) = 1 (বই উদাহরণ ২৭)
ধাপ ১: loga(abc) = x, logb(abc) = y, logc(abc) = z ধরি। সংজ্ঞা অনুযায়ী aˣ = abc, bʸ = abc, cᶻ = abc।
ধাপ ২: তাই a = (abc)1/x, b = (abc)1/y, c = (abc)1/z।
ধাপ ৩: গুণ করি: abc = (abc)1/x + 1/y + 1/z। বামপক্ষ (abc)¹।
ধাপ ৪: সূচক সমান: 1/x + 1/y + 1/z = 1, অর্থাৎ প্রমাণিত ✔।
৭) ডোমেন, রেঞ্জ ও বিপরীত: y = (4 − x)/(4 + x) (বই উদাহরণ ৩৬)
ধাপ ১ (ডোমেন): হর 4 + x = 0 হলে অসংজ্ঞায়িত। তাই ডোমেন = R − {−4}।
ধাপ ২ (বিপরীত): y(4 + x) = 4 − x ⇒ 4y + xy = 4 − x ⇒ x(y + 1) = 4 − 4y।
ধাপ ৩: x = 4(1 − y)/(1 + y)। চলক বদলে f⁻¹(x) = 4(1 − x)/(1 + x)।
ধাপ ৪: ln এর জন্য: g(x) = ln((4 − x)/(4 + x)) এ (4 − x)/(4 + x) > 0 লাগবে। ফল: −4 < x < 4, ডোমেন = (−4, 4)। (ল্যাব ৫ এ a = 4 দিয়ে দেখো।)

🧮 ল্যাব ১: সূচকের সূত্র যাচাই (ঠিক মান)

👉 ভিত্তি a এবং সূচক m, n বদলাও। ধনাত্মক, ঋণাত্মক ও শূন্য সূচকে সূত্রগুলো মেলে কিনা ঠিক মানে (ভগ্নাংশসহ) দেখো।

√ ল্যাব ২: মূল ও ভগ্নাংশ সূচক

👉 a, n ও m বদলাও। ল্যাব দেখাবে a এর n তম মূল আছে কিনা (ঋণাত্মক a ও জোড় n এ নেই) এবং am/n এর মান।

📈 ল্যাব ৩: y = aˣ ও y = logₐx এর লেখচিত্র

👉 ভিত্তি a বদলাও (a ≠ 1)। a > 1 ও a < 1 হলে বক্ররেখার আকার কেমন বদলায় দেখো। "দুটোই" নিলে ধূসর y = x রেখার সাপেক্ষে প্রতিসমতা দেখা যাবে।

🔢 ল্যাব ৪: লগারিদমের সূত্র

👉 ভিত্তি a, দুটি সংখ্যা M, N এবং ঘাত k বেছে নাও। যোগ, ভাগ, ঘাত ও ভিত্তি পরিবর্তনের সূত্র সংখ্যা দিয়ে মিলিয়ে দেখো।

🧭 ল্যাব ৫: ln ফাংশনের ডোমেন ও রেঞ্জ (উদাহরণ ৩১, ৩৬)

👉 f(x) = ln((a+x)/(a−x)) বা ln((a−x)/(a+x)) বেছে a ও x বদলাও। লাল ড্যাশ রেখা x = ±a। ডোমেনের বাইরে ফাংশন নেই। রেঞ্জ সব বাস্তব সংখ্যা।
