🎯 এই অধ্যায়ে শিখবে: বহুপদী, ভাগ সূত্র, ভাগশেষ ও উৎপাদক উপপাদ্য, উৎপাদকে বিশ্লেষণ, সমমাত্রিক-প্রতিসম-চক্রক্রমিক রাশি, বিশেষ সূত্র a³+b³+c³−3abc এবং আংশিক ভগ্নাংশ।

১. বহুপদী (Polynomial) ⭐⭐⭐

  • বহুপদী হলো এমন রাশি যার পদগুলো চলকের শুধু অঋণাত্মক পূর্ণসাংখ্যিক ঘাত ও ধ্রুবকের গুণফল। যেমন ২x² + ৭x + ৫। কিন্তু x⁻² বা √x থাকলে বহুপদী নয়।
  • cxᵖ পদে c = সহগ, p = পদের মাত্রা। সর্বোচ্চ মাত্রাটিই বহুপদীর মাত্রা, তার পদ মুখ্যপদ, সহগ মুখ্যসহগ। চলকবর্জিত পদ ধ্রুবপদ।
  • উদাহরণ: ২x⁶ − ৩x⁵ − x⁴ + ২x − ৫ এর মাত্রা ৬, মুখ্যপদ ২x⁶, মুখ্যসহগ ২, ধ্রুবপদ −৫।
  • আদর্শ রূপ: ঘাত বড় থেকে ছোট ক্রমে লেখা। P(x) লিখলে P(a) মানে x-এর জায়গায় a বসানো।
  • দুই চলকের বহুপদীর মাত্রা: প্রতিটি পদের ঘাতের যোগফলের সর্বোচ্চটি। P(x, y) = ৮x³ + y³ − ৪x²+ ৭xy + ২y − ৫ এর মাত্রা ৩।

২. ভাগ সূত্র ও ভাগশেষ উপপাদ্য ⭐⭐⭐

  • ভাগ সূত্র: P(x) = F(x)·Q(x) + R(x), যেখানে R = ০ অথবা R-এর মাত্রা < Q-এর মাত্রা। (সংখ্যার মতোই: ভাজ্য = ভাজক × ভাগফল + ভাগশেষ)
  • ভাগশেষ উপপাদ্য: P(x)-কে (x − a) দিয়ে ভাগ করলে ভাগশেষ = P(a)। অর্থাৎ ভাগ না করেই ভাগশেষ জানা যায়!
  • (ax + b) দিয়ে ভাগ করলে ভাগশেষ = P(−b/a)।
  • উৎপাদক উপপাদ্য: P(a) = ০ হলে (x − a) হলো P(x)-এর উৎপাদক, আর উল্টোটাও সত্য।
  • x − ১ উৎপাদক হবে যদি ও কেবল যদি সহগগুলোর যোগফল ০ হয়। (ax³+bx²+cx+d এর জন্য a+b+c+d = ০)

৩. অভেদ ও সমতা সূত্র ⭐⭐

  • অভেদ (≡): চলকের সকল মানের জন্য সত্য। যেমন (x + y)² ≡ x² + ২xy + y²। আর সমীকরণ শুধু কিছু মানের জন্য সত্য।
  • সমতা সূত্র: দুটি বহুপদী অভেদ হলে অনুরূপ পদের সহগ সমান। ax² + bx + c ≡ px² + qx + r হলে a = p, b = q, c = r।

৪. উৎপাদকে বিশ্লেষণ (মূলদ মূল পদ্ধতি) ⭐⭐⭐

  • সহগ পূর্ণসংখ্যা হলে P(x)-এর মূলদ মূল r = p/q (লঘিষ্ঠ আকারে) এর জন্য p হলো ধ্রুবপদের উৎপাদক এবং q হলো মুখ্যসহগের উৎপাদক।
  • তাই সম্ভাব্য সব ±p/q নিয়ে P বসিয়ে পরীক্ষা করো। যেটায় ০ হয় সেটাই উৎপাদক।
  • উদাহরণ: x³ − ৬x² + ১১x − ৬ এ ধ্রুবপদ −৬। সম্ভাব্য মান ±১, ±২, ±৩, ±৬। P(১) = P(২) = P(৩) = ০, তাই (x−১)(x−২)(x−৩)।

৫. সমমাত্রিক, প্রতিসম ও চক্রক্রমিক রাশি ⭐⭐⭐

  • সমমাত্রিক: প্রতিটি পদের মাত্রা একই। x² + ২xy + ৫y² (প্রতিটি ২ মাত্রার)।
  • প্রতিসম: যেকোনো দুটি চলক বদলালে রাশি একই থাকে। a+b+c, ab+bc+ca, a²+b²+c²।
  • চক্রক্রমিক: a→b, b→c, c→a (গোল ঘুরিয়ে) বসালে রাশি একই থাকে। a²b + b²c + c²a চক্রক্রমিক, কিন্তু প্রতিসম নয়।
  • মনে রাখো: তিন চলকে প্রতিটি প্রতিসম রাশি চক্রক্রমিক। কিন্তু প্রতিটি চক্রক্রমিক রাশি প্রতিসম নয়।
  • চক্রক্রমিক রাশির (a − b) উৎপাদক হলে (b − c) ও (c − a) ও উৎপাদক হয়।
  • এক মাত্রার চক্রক্রমিক: k(a+b+c)। দুই মাত্রার: k(a²+b²+c²) + m(ab+bc+ca)।

৬. বিশেষ সূত্র ⭐⭐⭐

  • a³ + b³ + c³ − ৩abc = (a + b + c)(a² + b² + c² − ab − bc − ca)
  • অনুসিদ্ধান্ত: = ½(a+b+c){(a−b)² + (b−c)² + (c−a)²}।
  • a + b + c = ০ হলে a³ + b³ + c³ = ৩abc। আবার a³+b³+c³ = ৩abc হলে a+b+c = ০ অথবা a = b = c।
  • (a−b)³ + (b−c)³ + (c−a)³ = ৩(a−b)(b−c)(c−a) (কারণ (a−b)+(b−c)+(c−a) = ০)।

৭. মূলদ ও আংশিক ভগ্নাংশ ⭐⭐⭐

  • প্রকৃত ভগ্নাংশ: লবের মাত্রা < হরের মাত্রা। অপ্রকৃত: লবের মাত্রা ≥ হরের মাত্রা। অপ্রকৃত হলে আগে ভাগ করে ভাগফল + প্রকৃত ভগ্নাংশ করে নাও।
  • ক) আলাদা একঘাত উৎপাদক: (px+q)/((x−a)(x−b)) = A/(x−a) + B/(x−b)। দুই পাশ গুণ করে x = a ও x = b বসাও।
  • খ) পুনরাবৃত্ত একঘাত: (x−a)² থাকলে A/(x−a) + B/(x−a)² লেখো।
  • গ) দ্বিঘাত উৎপাদক (যা ভাঙে না): (x²+৪) থাকলে লব হবে (Bx + C)/(x²+৪)।
  • ঘ) পুনরাবৃত্ত দ্বিঘাত: (x²+১)² থাকলে (Bx+C)/(x²+১) + (Dx+E)/(x²+১)²।
⚠️ সাধারণ ভুল: ① P(a) বের করার সময় ঋণাত্মক সংখ্যায় বন্ধনী না দেওয়া, যেমন (−২)³ = −৮। ② (x + ২) দিয়ে ভাগে a = −২ নিতে ভুলে যাওয়া। ③ অপ্রকৃত ভগ্নাংশে ভাগ না করেই আংশিক ভগ্নাংশ শুরু করা।

🪜 ধাপে ধাপে উদাহরণ (বই থেকে)

👉 "পরের ধাপ" চাপো। আগে নিজে চেষ্টা করো, তারপর মিলিয়ে নাও।
উদাহরণ ১ (বই উ. ৮): P(x) = ৫x³ + ৬x² − ax + ৬ কে (x − ২) দিয়ে ভাগ করলে ভাগশেষ ৬। a এর মান কত?
ধাপ ১: ভাগশেষ উপপাদ্য: ভাগশেষ = P(২)।
ধাপ ২: P(২) = ৫·৮ + ৬·৪ − ২a + ৬ = ৪০ + ২৪ − ২a + ৬ = ৭০ − ২a।
ধাপ ৩: শর্ত: ৭০ − ২a = ৬ ⇒ ২a = ৬৪ ⇒ a = ৩২।
উদাহরণ ২ (বই উ. ১২): P(x) = x³ − ৬x² + ১১x − ৬ কে উৎপাদকে বিশ্লেষণ করো।
ধাপ ১: ধ্রুবপদ −৬ এর উৎপাদক: ±১, ±২, ±৩, ±৬। মুখ্যসহগ ১, তাই মূলগুলো এগুলোর মধ্যে।
ধাপ ২: P(১) = ১ − ৬ + ১১ − ৬ = ০ ✔ ⇒ (x − ১) উৎপাদক। P(−১) = −২৪ ≠ ০।
ধাপ ৩: P(২) = ৮ − ২৪ + ২২ − ৬ = ০ ✔ ⇒ (x − ২)। P(৩) = ২৭ − ৫৪ + ৩৩ − ৬ = ০ ✔ ⇒ (x − ৩)।
ধাপ ৪: মাত্রা ৩ আর ৩টি একঘাত উৎপাদক পেলাম। মুখ্যসহগ ১, তাই P(x) = (x − ১)(x − ২)(x − ৩)।
উদাহরণ ৩ (বই উ. ১৩): ১৮x³ + ১৫x² − x − ২ কে উৎপাদকে বিশ্লেষণ করো।
ধাপ ১: ধ্রুবপদ −২ এর উৎপাদক: ±১, ±২। মুখ্যসহগ ১৮ এর উৎপাদক: ১, ২, ৩, ৬, ৯, ১৮। সম্ভাব্য মূল r/s।
ধাপ ২: পরীক্ষা করে পাই P(−১/২) = ১৮(−১/৮) + ১৫(১/৪) + ১/২ − ২ = −২.২৫ + ৩.৭৫ + ০.৫ − ২ = ০ ✔। তাই (২x + ১) উৎপাদক।
ধাপ ৩: ভাগ করলে ভাগফল ৯x² + ৩x − ২।
ধাপ ৪: ৯x² + ৩x − ২ = ৯x² + ৬x − ৩x − ২ = ৩x(৩x + ২) − ১(৩x + ২) = (৩x + ২)(৩x − ১)।
ধাপ ৫: ১৮x³ + ১৫x² − x − ২ = (২x + ১)(৩x + ২)(৩x − ১)। (গুণ করে মিলিয়ে দেখো।)
উদাহরণ ৪ (বই উ. ১৫): bc(b − c) + ca(c − a) + ab(a − b) কে উৎপাদকে বিশ্লেষণ করো (সহজ পদ্ধতি)।
ধাপ ১: রাশিটি a এর বহুপদী P(a) ধরি। a এর জায়গায় b বসালে: bc(b−c) + cb(c−b) + b²(b−b) = ০ ✔।
ধাপ ২: তাই (a − b) উৎপাদক। রাশিটি চক্রক্রমিক, তাই (b − c) ও (c − a) ও উৎপাদক।
ধাপ ৩: রাশিটি ৩ মাত্রার সমমাত্রিক, ৩টি একঘাত উৎপাদক পেয়েছি। অতএব রাশি = k(a−b)(b−c)(c−a), k ধ্রুবক।
ধাপ ৪: a = ০, b = ১, c = ২ বসাই। বামপক্ষ = ১·২·(১−২) = −২। ডানপক্ষ = k(−১)(−১)(২) = ২k। তাই k = −১।
ধাপ ৫: উত্তর: −(a − b)(b − c)(c − a)।
উদাহরণ ৫ (বই উ. ২৩): (৫x − ৭)/((x−১)(x−২)) কে আংশিক ভগ্নাংশে প্রকাশ করো।
ধাপ ১: ধরি (৫x−৭)/((x−১)(x−২)) ≡ A/(x−১) + B/(x−২)।
ধাপ ২: দুই পাশে (x−১)(x−২) গুণ: ৫x − ৭ ≡ A(x−২) + B(x−১)।
ধাপ ৩: x = ১ বসাই: −২ = −A ⇒ A = ২। x = ২ বসাই: ৩ = B।
ধাপ ৪: উত্তর: ২/(x−১) + ৩/(x−২)। যাচাই: ২(x−২) + ৩(x−১) = ৫x − ৭ ✔
উদাহরণ ৬ (বই উ. ২৫): (x−১)(x−৫)/((x−২)(x−৪)) কে আংশিক ভগ্নাংশে প্রকাশ করো। (অপ্রকৃত ভগ্নাংশ)
ধাপ ১: লব ও হর দুটিই ২ মাত্রার, তাই ভগ্নাংশ অপ্রকৃত। লবকে হর দিয়ে ভাগ করলে ভাগফল ১। ধরি = ১ + A/(x−২) + B/(x−৪)।
ধাপ ২: গুণ করে: (x−১)(x−৫) ≡ (x−২)(x−৪) + A(x−৪) + B(x−২)।
ধাপ ৩: x = ২: (১)(−৩) = −৩ = A(−২) ⇒ A = ৩/২। x = ৪: (৩)(−১) = −৩ = B(২) ⇒ B = −৩/২।
ধাপ ৪: উত্তর: ১ + ৩/(২(x−২)) − ৩/(২(x−৪))।
উদাহরণ ৭ (বই উ. ২৯): ১/(x(x²+১)²) কে আংশিক ভগ্নাংশে প্রকাশ করো।
ধাপ ১: ধরি = A/x + (Bx + C)/(x²+১) + (Dx + E)/(x²+১)²।
ধাপ ২: গুণ করে: ১ ≡ A(x²+১)² + (Bx+C)(x²+১)x + (Dx+E)x।
ধাপ ৩: x = ০ বসিয়ে A = ১। এরপর x⁴, x³, x², x এর সহগ তুলনা: A + B = ০, C = ০, ২A + B + D = ০, C + E = ০।
ধাপ ৪: সমাধান: B = −১, C = ০, D = −১, E = ০।
ধাপ ৫: উত্তর: ১/x − x/(x²+১) − x/(x²+১)²।

📊 ল্যাব ১: বহুপদী চেনো ও মান বের করো

👉 সহগগুলো বড় ঘাত থেকে ছোট ঘাত ক্রমে কমা দিয়ে লেখো। যেমন ৩, ২, −৭, ৮ মানে ৩x³ + ২x² − ৭x + ৮। তারপর x-এর মান বদলাও।

➗ ল্যাব ২: ভাগশেষ উপপাদ্য ও সিনথেটিক ভাগ

👉 বহুপদী ও ভাজক লেখো (যেমন x-2, x+3 বা 2x-1)। ভাগ না করেই P(a) দিয়ে ভাগশেষ মিলিয়ে দেখো।
উদাহরণ: বইয়ের কাজ — P(x) = ২x⁴ − ৬x³ + ৫x − ২ কে x−১, x−২, x+২, x+৩, ২x−১, ২x+১ দিয়ে ভাগ করে ভাগশেষ দেখো।

🔍 ল্যাব ৩: উৎপাদক খোঁজার মেশিন (মূলদ মূল পরীক্ষা)

👉 পূর্ণসংখ্যা সহগ লেখো। মেশিন সম্ভাব্য সব ±p/q পরীক্ষা করে উৎপাদক বের করবে। ডিফল্টে বইয়ের উদাহরণ ১৩।

🔄 ল্যাব ৪: প্রতিসম না চক্রক্রমিক?

👉 একটি রাশি বেছে নাও। মেশিন নানা সংখ্যা বসিয়ে (দুটি চলক বদল ও গোল ঘুরিয়ে) পরীক্ষা করে বলবে।

⚖️ ল্যাব ৫: বিশেষ সূত্র মিলিয়ে দেখো

👉 a, b, c এর যেকোনো মান দাও। বাম ও ডান পাশ সবসময় সমান হবে (অভেদ!)। "a+b+c = ০ করো" চাপলে ৩abc সূত্র দেখো।

🧩 ল্যাব ৬: আংশিক ভগ্নাংশ মেশিন

👉 লবের সহগ (বড় ঘাত থেকে) ও হরের মূলগুলো লেখো। যেমন লব ৫, −৭ ও মূল ১, ২ মানে (৫x−৭)/((x−১)(x−২))।
এই মেশিন হরে আলাদা একঘাত উৎপাদক (x−a)(x−b)… থাকলে কাজ করে। পুনরাবৃত্ত বা দ্বিঘাত উৎপাদকের জন্য ধাপে ধাপে উদাহরণ ৭ দেখো।

✍️ প্র্যাকটিস (বইয়ের ধাঁচে)

👉 নিজে হিসাব করে উত্তর লেখো। ভগ্নাংশ হলে −১/৮ এভাবে লেখো। বাংলা বা ইংরেজি সংখ্যা চলবে।
