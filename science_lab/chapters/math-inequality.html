⚖️ অসমতা

📝 নোট🪜 ধাপে ধাপে📏 এক চলক🗺️ লেখচিত্র🛒 বাজেট🎯 দুই অসমতা✍️ প্র্যাকটিস❓ কুইজ📖 প্রশ্নোত্তর

📝 সহজ নোট

🎯 এই অধ্যায়ে শিখবে: অসমতা কী, অসমতার নিয়ম, এক চলকের অসমতা সমাধান ও সংখ্যারেখায় দেখানো, বাস্তব সমস্যাকে অসমতা বানানো, এবং দুই চলকের অসমতার লেখচিত্র (ছায়াচিত্র)।

১. অসমতার ধারণা ⭐⭐

  • সমীকরণে দুই পক্ষ সমান। অসমতায় একপক্ষ অপরপক্ষ থেকে বড় বা ছোট। চিহ্ন: > (বড়), < (ছোট), ≥ (বড় অথবা সমান), ≤ (ছোট অথবা সমান)।
  • a > b ⇔ (a − b) ধনাত্মক এবং a < b ⇔ (a − b) ঋণাত্মক।
  • a ≥ b মানে a > b অথবা a = b। তাই 3 ≥ 1 সত্য (কারণ 3 > 1) এবং 2 ≤ 4 সত্য।
  • a < b < c মানে a < b এবং b < c।
  • বাস্তব জীবনে ব্যবহার: ক্লাসে উপস্থিত ছাত্র 0 < x < 200, পরীক্ষার নম্বর 0 ≤ x ≤ 1000, ইত্যাদি।

২. অসমতার বিধি ⭐⭐⭐

  • a < b ⇔ b > a।
  • a > b হলে যেকোনো c এর জন্য a + c > b + c এবং a − c > b − c। অর্থাৎ যোগ-বিয়োগে দিক বদলায় না।
  • a > b এবং c > 0 হলে ac > bc, a/c > b/c। (দিক ঠিক থাকে)
  • a > b এবং c < 0 হলে ac < bc, a/c < b/c। (দিক উল্টে যায়!)
⚠️ সবচেয়ে বড় ভুল: ঋণাত্মক সংখ্যা দিয়ে গুণ বা ভাগ করলে অসমতার চিহ্ন উল্টাতে ভুলে যাওয়া। যেমন −2x > 10 ⇒ x < −5 (x > −5 নয়)।

৩. এক চলকের অসমতা সমাধান ⭐⭐⭐

  • সমীকরণের মতোই x এক পাশে আনো (যোগ/বিয়োগ করে), তারপর x এর সহগ দিয়ে ভাগ করো। সহগ ঋণাত্মক হলে চিহ্ন উল্টাও।
  • উদাহরণ ৩: 4x + 4 > 16 ⇒ 4x > 12 ⇒ x > 3। সমাধান সেট S = {x ∈ R : x > 3}।
  • সমাধান সেট সাধারণত বাস্তব সংখ্যার একটি অসীম উপসেট (সমীকরণের মতো কয়েকটি মান নয়)।
  • সাধারণ রূপ: a(x + b) < c। a > 0 হলে x < c/a − b, আর a < 0 হলে x > c/a − b।
  • বিশেষ দ্রষ্টব্য: a = 0 হলে 0·(x + b) < c। c ধনাত্মক হলে x এর যেকোনো মানের জন্য সত্য, c ঋণাত্মক হলে কোনো সমাধান নেই।

৪. সংখ্যারেখায় দেখানো ⭐⭐

  • খালি বৃত্ত ○: বিন্দুটি সমাধানের মধ্যে নেই (> বা < এর জন্য)।
  • ভরাট বৃত্ত ●: বিন্দুটি সমাধানের মধ্যে আছে (≥ বা ≤ এর জন্য)।
  • x > 3 হলে বৃত্ত থেকে ডানে তীর, x < −5 হলে বামে তীর।

৫. অসমতার ব্যবহার ⭐⭐⭐

  • "অনূর্ধ্ব" বা "বেশি নয়" মানে ≤। "কমপক্ষে" বা "সর্বনিম্ন" মানে ≥। "অপেক্ষা কম/বেশি" মানে < / >।
  • উদাহরণ ৬: রমা পেয়েছে 5x + 6x নম্বর, কুমকুম 4x + 84। রমা পায়নি বেশি ⇒ 11x < 4x + 84 ⇒ x < 12। আবার কুমকুমের বাংলা সর্বনিম্ন 40 ⇒ 4x ≥ 40 ⇒ x ≥ 10। তাই 10 ≤ x < 12।
  • উদাহরণ ৭: 5x + 8(x + 4) ≤ 97 ⇒ 13x ≤ 65 ⇒ x ≤ 5। তাই সর্বাধিক ৫টি পেন্সিল।
  • উত্তর বাস্তবসম্মত কিনা দেখো (গুনতি সংখ্যা হলে পূর্ণসংখ্যা, ঋণাত্মক নয়)।

৬. দুই চলকের অসমতা ও লেখচিত্র ⭐⭐⭐

  • ax + by + c = 0 একটি সরলরেখা। রেখাটি সমতলকে তিনটি অংশে ভাগ করে: রেখার এক পাশ, অপর পাশ, আর রেখার উপরের বিন্দুগুলো।
  • এক পাশের সব বিন্দুতে ax + by + c ধনাত্মক, অপর পাশে ঋণাত্মক, রেখার উপর শূন্য।
  • পরীক্ষা বিন্দু: মূলবিন্দু (0, 0) (রেখার উপর না থাকলে) বসিয়ে দেখো অসমতা সত্য কিনা। সত্য হলে মূলবিন্দুর পাশ, মিথ্যা হলে বিপরীত পাশ ছায়া দাও।
  • উদাহরণ: x + y − 3 > 0। মূলবিন্দুতে −3 > 0 মিথ্যা। তাই রেখার যে পাশে মূলবিন্দু নেই, সেই পাশ।
  • > বা < হলে রেখা ডটেড (ছাড়া), ≥ বা ≤ হলে রেখা অন্তর্ভুক্ত (পূর্ণ রেখা)।
  • y ≤ 2x হলে মূলবিন্দু রেখার উপরেই, তাই অন্য বিন্দু যেমন (1, 0) দিয়ে পরীক্ষা করো।
  • x > −5/2 এর মতো অসমতা Y অক্ষের সমান্তরাল রেখার একপাশ।

🪜 ধাপে ধাপে

👉 "পরের ধাপ" চাপতে থাকো।
১) x − 9 > 3x + 1 (বই উদাহরণ ৪): সমাধান ও সংখ্যারেখা
ধাপ ১: দুই পক্ষে 9 যোগ করি: x > 3x + 10।
ধাপ ২: দুই পক্ষ থেকে 3x বিয়োগ: −2x > 10।
ধাপ ৩: −2 দিয়ে ভাগ করি। ঋণাত্মক সংখ্যা দিয়ে ভাগ, তাই চিহ্ন উল্টাবে: x < −5।
ধাপ ৪: সংখ্যারেখায় −5 এ খালি বৃত্ত (○), বামে তীর। সমাধান সেট S = {x ∈ R : x < −5}।
ধাপ ৫: যাচাই: x = −6 বসালে বামে −6 − 9 = −15, ডানে 3(−6) + 1 = −17। −15 > −17 ✔। আর x = 0 বসালে −9 > 1 ✘, তাই 0 সমাধান নয়।
২) রমা ও কুমকুমের নম্বর (বই উদাহরণ ৬): রমা পেয়েছে 5x ও 6x নম্বর, কুমকুম 4x ও 84। কেউ 40 এর নিচে পায়নি। বাংলায় কুমকুম প্রথম, রমা দ্বিতীয়।
ধাপ ১: রমার মোট 5x + 6x = 11x এবং কুমকুমের মোট 4x + 84।
ধাপ ২: কুমকুম প্রথম ⇒ রমার মোট কম: 11x < 4x + 84 ⇒ 7x < 84 ⇒ x < 12।
ধাপ ৩: কেউ 40 এর নিচে পায়নি। কুমকুমের একটি নম্বর 4x ⇒ 4x ≥ 40 ⇒ x ≥ 10।
ধাপ ৪: দুটি শর্ত একসাথে: 10 ≤ x < 12। (x পূর্ণসংখ্যা হলে 10 বা 11)
৩) পেন্সিল ও খাতা (বই উদাহরণ ৭): 5 টাকা দরে x টি পেন্সিল ও 8 টাকা দরে (x + 4) টি খাতা, মোট মূল্য অনূর্ধ্ব 97 টাকা।
ধাপ ১: পেন্সিলের দাম 5x, খাতার দাম 8(x + 4)।
ধাপ ২: "অনূর্ধ্ব 97" মানে ≤ 97। তাই 5x + 8(x + 4) ≤ 97।
ধাপ ৩: 5x + 8x + 32 ≤ 97 ⇒ 13x ≤ 65 ⇒ x ≤ 5।
ধাপ ৪: পেন্সিল গুনতি সংখ্যা, তাই সর্বাধিক ৫টি। যাচাই: 5·5 + 8·9 = 25 + 72 = 97 ✔।
৪) x + y − 3 > 0 এর ছায়াচিত্র (বই উদাহরণ ৯)
ধাপ ১: প্রথমে রেখা x + y − 3 = 0 আঁকি। বিন্দু (0, 3), (3, 0), (1, 2)।
ধাপ ২: > চিহ্ন (≥ নয়), তাই রেখা অন্তর্ভুক্ত নয়, ডটেড করে আঁকি।
ধাপ ৩: মূলবিন্দু (0, 0) বসিয়ে 0 + 0 − 3 = −3। −3 > 0 মিথ্যা।
ধাপ ৪: মূলবিন্দু যে পাশে, সেই পাশ সমাধান নয়। তাই রেখার বিপরীত পাশ (উপরের-ডান পাশ) ছায়া দিই।
ধাপ ৫: যাচাই: (3, 3) এ 3 + 3 − 3 = 3 > 0 ✔ ছায়াংশে আছে।
৫) y ≤ 2x (বই উদাহরণ ১২): মূলবিন্দু রেখার উপরেই!
ধাপ ১: y − 2x ≤ 0 লিখি। রেখা y = 2x, বিন্দু (0,0), (2,4), (−2,−4)।
ধাপ ২: ≤ আছে, তাই রেখা অন্তর্ভুক্ত (পূর্ণ রেখা)।
ধাপ ৩: মূলবিন্দু রেখার উপর, তাই (0,0) পরীক্ষা বিন্দু হতে পারে না। অন্য বিন্দু (1, 0) নিই।
ধাপ ৪: (1, 0) এ y − 2x = 0 − 2 = −2 ≤ 0 সত্য ✔। তাই (1, 0) যে পাশে, অর্থাৎ রেখার নিচের-ডান পাশ ছায়া দিই।

📏 ল্যাব ১: এক চলকের অসমতা + সংখ্যারেখা

👉 অসমতা: ax + b ▢ cx + d। চিহ্ন বেছে নাও, স্লাইডার নাড়াও। সমাধান ধাপে ধাপে, চিহ্ন কখন উল্টায় আর সংখ্যারেখা দেখবে। নিচের "পরীক্ষা x" স্লাইডারে যেকোনো মান বসিয়ে দেখো সত্য কিনা।

🗺️ ল্যাব ২: দুই চলকের অসমতার লেখচিত্র

👉 ax + by + c ▢ ০ এর ছায়াচিত্র দেখো। ছবির উপর সবুজ/লাল বিন্দুটি টেনে যেকোনো জায়গায় নাও। ল্যাব বলবে ওই বিন্দুতে মান কত ও অসমতা সত্য কিনা। ডিফল্ট: x + y − 3 > 0 (বই উদাহরণ ৯)।

🛒 ল্যাব ৩: বাজেট থেকে অসমতা (বই উদাহরণ ৭)

👉 একজন ছাত্র a টাকা দরে x টি পেন্সিল ও b টাকা দরে (x + k) টি খাতা কেনে। মোট মূল্য অনূর্ধ্ব M টাকা। সর্বাধিক কয়টি পেন্সিল কিনতে পারবে? ডিফল্ট মানে বইয়ের উদাহরণ (a = ৫, b = ৮, k = ৪, M = ৯৭)।

🎯 ল্যাব ৪: দুটি অসমতার সাধারণ অংশ

👉 দুটি অসমতার ছায়াচিত্র একসাথে। নীল = প্রথমটির সমাধান, কমলা = দ্বিতীয়টির, সবুজ = দুটিরই সমাধান (সাধারণ অংশ)। বিন্দু টেনে পরীক্ষা করো। ডিফল্ট: x + y − 3 > 0 এবং 2x − 3y + 6 ≥ 0 (বইয়ের উদাহরণ ৯ ও ১০)।

✍️ প্র্যাকটিস (বইয়ের ধাঁচে)

👉 সীমান্তের (boundary) মান লেখো। যেমন x > ৩ হলে ৩ লেখো।
