📝 সহজ নোট

🎯 এই অধ্যায়ে শিখবে: দ্বিঘাত সমীকরণের সূত্র ও নিশ্চায়ক, বর্গমূলচিহ্নযুক্ত সমীকরণ (অবান্তর মূল চেনা), সূচক সমীকরণ, দুই চলকের দ্বিঘাত সহসমীকরণ, বাস্তব সমস্যা থেকে সমীকরণ গঠন এবং লেখচিত্রে সমাধান।

১. দ্বিঘাত সমীকরণ ও সূত্র ⭐⭐⭐

ax² + bx + c = 0 (a ≠ 0) ⇒ x = (−b ± √(b² − 4ac)) / 2a
  • বর্গ পূর্ণ করে এই সূত্র পাওয়া যায় (নিচের "ধাপে ধাপে" অংশে দেখো)।
  • দুটি মূল: x₁ = (−b + √(b²−4ac))/2a এবং x₂ = (−b − √(b²−4ac))/2a।
  • নিশ্চায়ক (Discriminant) D = b² − 4ac: এটি মূলের ধরন ঠিক করে।
D এর অবস্থামূলদ্বয়ের প্রকৃতি
D > 0 এবং পূর্ণবর্গবাস্তব, অসমান ও মূলদ
D > 0 কিন্তু পূর্ণবর্গ নয়বাস্তব, অসমান ও অমূলদ
D = 0বাস্তব ও পরস্পর সমান (x = −b/2a)
D < 0বাস্তব মূল নেই

২. বর্গমূলচিহ্নযুক্ত সমীকরণ ⭐⭐⭐

  • বর্গমূল আলাদা করে দুই পক্ষ বর্গ করো। দরকার হলে আবার বর্গ করো, যতক্ষণ বর্গমূল না থাকে।
  • বর্গ করলে কখনো কখনো এমন মূল আসে যা আসল সমীকরণকে সিদ্ধ করে না। এদের অবান্তর মূল (Extraneous root) বলে।
  • তাই শুদ্ধি পরীক্ষা বাধ্যতামূলক: প্রতিটি মূল আসল সমীকরণে বসিয়ে মিলিয়ে নাও।
  • উদাহরণ: √(x+6) = x থেকে x² − x − 6 = 0 ⇒ x = 3 বা −2। কিন্তু x = −2 হলে ডানপক্ষ −২, আর বর্গমূল কখনো ঋণাত্মক হয় না, তাই −2 অবান্তর। উত্তর x = 3।

৩. সূচক সমীকরণ ⭐⭐⭐

  • মূল নিয়ম: a > 0, a ≠ 1 হলে aˣ = aᵐ ⇔ x = m। তাই দুই পক্ষকে একই ভিত্তির ঘাত করো।
  • যেমন 2^(x+7) = 4^(x+2) = 2^(2x+4) ⇒ x + 7 = 2x + 4 ⇒ x = 3।
  • দুই ভিত্তি আলাদা হলে (যেমন 5^(3x−7) = 3^(3x−7)) ঘাত শূন্য করো: (a/b)^k = 1 = (a/b)⁰ ⇒ k = 0।
  • দ্বিঘাতের মতো সূচক সমীকরণে p = aˣ ধরো। মনে রাখো aˣ > 0, তাই ঋণাত্মক p বাদ। যেমন 3^(2x−2) − 5·3^(x−2) − 66 = 0 ⇒ p² − 5p − 594 = 0 ⇒ (p − 27)(p + 22) = 0 ⇒ p = 27 ⇒ x = 3।

৪. দুই চলকের সহসমীকরণ জোট ⭐⭐⭐

  • একটি একঘাত ও একটি দ্বিঘাত হলে একঘাত থেকে y বের করে দ্বিঘাতে বসাও (প্রতিস্থাপন)।
  • x² + y² ও xy দেওয়া থাকলে: (x+y)² = x² + y² + 2xy এবং (x−y)² = x² + y² − 2xy। তারপর x ± y এর মান বের করে যোগ-বিয়োগ করো।
  • সমঘাত সমীকরণ (যেমন x² − 2xy + 8y² = 8, 3xy − 2y² = 4): ভাগ করে x² − 8xy + 12y² = 0 পেয়ে উৎপাদকে ভাঙো ⇒ x = 6y বা x = 2y।
  • সূচক জোটে প্রথমে দুই সমীকরণের ভিত্তি এক করে ঘাত সমান করো, তারপর একঘাত জোট হিসেবে সমাধান করো।
  • জোটের সমাধান (x, y) = (a, b) জোড়া। দুই সমীকরণই সিদ্ধ হলে তবেই গ্রহণযোগ্য।

৫. বাস্তব সমস্যা থেকে সমীকরণ ⭐⭐

  • অজানা রাশি x, y ধরে প্রশ্নের শর্ত থেকে সমীকরণ লেখো, তারপর সমাধান করো।
  • উত্তর বাস্তবসম্মত কিনা দেখো: দৈর্ঘ্য ঋণাত্মক হয় না, অঙ্ক ভগ্নাংশ বা ঋণাত্মক হয় না। এমন মূল বাদ দাও।
  • দুই অঙ্কের সংখ্যা: দশকের অঙ্ক x, এককের অঙ্ক y হলে সংখ্যা = 10x + y, স্থান বিনিময় করলে 10y + x।

৬. লেখচিত্রে দ্বিঘাত সমীকরণ ⭐⭐

  • y = ax² + bx + c ধরলে লেখচিত্র একটি প্যারাবোলা। যেসব x এর জন্য y = 0, প্যারাবোলা সেখানে x-অক্ষকে ছেদ করে, ওগুলোই সমীকরণের মূল।
  • দুই বিন্দুতে ছেদ ⇒ দুটি ভিন্ন মূল (D > 0)। একটি বিন্দুতে স্পর্শ ⇒ সমান মূল (D = 0)। ছেদ নেই ⇒ বাস্তব মূল নেই (D < 0)।
⚠️ সাধারণ ভুল: ① বর্গ করার পর শুদ্ধি পরীক্ষা না করা। ② ঘাতকে সূত্রে 2a-এর জায়গায় শুধু a দিয়ে ভাগ করা। ③ সূচকে ভিত্তি এক না করে সরাসরি ঘাত সমান করা। ④ বাস্তব সমস্যায় ঋণাত্মক দৈর্ঘ্য রেখে দেওয়া।

🪜 ধাপে ধাপে (সূত্র ও অবান্তর মূল)

👉 "পরের ধাপ" চাপতে থাকো, যুক্তি একটার পর একটা খুলবে।
১) সূত্রটা কীভাবে এলো? ax² + bx + c = 0 থেকে x এর সূত্র।
ধাপ ১: দুই পক্ষকে a দিয়ে গুণ করি: a²x² + abx + ac = 0।
ধাপ ২: (ax)² + 2·(ax)·(b/2) + (b/2)² − (b/2)² + ac = 0। অর্থাৎ বর্গ পূর্ণ করার জন্য (b/2)² যোগ-বিয়োগ করলাম।
ধাপ ৩: (ax + b/2)² = b²/4 − ac = (b² − 4ac)/4।
ধাপ ৪: বর্গমূল করে ax + b/2 = ± √(b² − 4ac)/2।
ধাপ ৫: ax = −b/2 ± √(b² − 4ac)/2। দুই পক্ষকে a দিয়ে ভাগ করলে x = (−b ± √(b² − 4ac)) / 2a ✔
২) x² − 2x − 2 = 0 (বই উদাহরণ ৩)
ধাপ ১: a = 1, b = −2, c = −2। D = (−2)² − 4·1·(−2) = 4 + 8 = 12।
ধাপ ২: x = (2 ± √12)/2। √12 = 2√3।
ধাপ ৩: x = (2 ± 2√3)/2 = 1 ± √3। অর্থাৎ x₁ = 1 + √3 ≈ 2.73, x₂ = 1 − √3 ≈ −0.73।
ধাপ ৪: D = 12 পূর্ণবর্গ নয়, তাই মূল দুটি বাস্তব, অসমান ও অমূলদ। 😊 উৎপাদক বিশ্লেষণ না পারলেও সূত্র দিয়ে সমাধান হলো।
৩) √(2x+9) − √(x−4) = √(x+1) (বই উদাহরণ ৭)
ধাপ ১: বর্গ করি: (2x+9) + (x−4) − 2√((2x+9)(x−4)) = x + 1 ⇒ 2x + 4 − 2√((2x+9)(x−4)) = 0।
ধাপ ২: √((2x+9)(x−4)) = x + 2।
ধাপ ৩: আবার বর্গ: (2x+9)(x−4) = (x+2)² ⇒ 2x² + x − 36 = x² + 4x + 4 ⇒ x² − 3x − 40 = 0।
ধাপ ৪: (x − 8)(x + 5) = 0 ⇒ x = 8 বা x = −5।
ধাপ ৫ (শুদ্ধি): x = 8: বামপক্ষ = √25 − √4 = 5 − 2 = 3, ডানপক্ষ = √9 = 3 ✔। x = −5: √(−1) বাস্তব নয় ✘।
ধাপ ৬: নির্ণেয় সমাধান x = 8। (x = −5 অবান্তর মূল)
৪) 3^(2x−2) − 5·3^(x−2) − 66 = 0 (বই উদাহরণ ১৭)
ধাপ ১: 3^(2x−2) = 3^(2x)/9 এবং 3^(x−2) = 3^x/9। দুই পক্ষকে 9 দিয়ে গুণ: 3^(2x) − 5·3^x − 594 = 0।
ধাপ ২: p = 3ˣ ধরি। p² − 5p − 594 = 0।
ধাপ ৩: p² − 27p + 22p − 594 = 0 ⇒ (p − 27)(p + 22) = 0।
ধাপ ৪: p = 3ˣ > 0, তাই p = −22 হতে পারে না। অতএব p = 27 = 3³ ⇒ x = 3 ✔
ধাপ ৫: যাচাই: 3⁴ − 5·3 − 66 = 81 − 15 − 66 = 0 ✔।
৫) x² + y² = 61, xy = −30 (বই উদাহরণ ২১)
ধাপ ১: (x − y)² = x² + y² − 2xy = 61 + 60 = 121 ⇒ x − y = ±11।
ধাপ ২: (x + y)² = 61 − 60 = 1 ⇒ x + y = ±1।
ধাপ ৩: চার জোড়া একঘাত জোট: (x+y, x−y) = (1, 11), (1, −11), (−1, 11), (−1, −11)।
ধাপ ৪: সমাধান: (6, −5), (−5, 6), (5, −6), (−6, 5)।
ধাপ ৫: যাচাই (6, −5): 36 + 25 = 61 ✔, 6 × (−5) = −30 ✔।
৬) দুই অঙ্কের সংখ্যা (বই উদাহরণ ২৬): সংখ্যাকে অঙ্কদ্বয়ের গুণফল দিয়ে ভাগ করলে ভাগফল 3; সংখ্যার সাথে 18 যোগ করলে অঙ্কদ্বয় স্থান বিনিময় করে।
ধাপ ১: দশকের অঙ্ক x, এককের অঙ্ক y। সংখ্যা = 10x + y।
ধাপ ২: (10x + y)/(xy) = 3 ⇒ 10x + y = 3xy ... (১)
ধাপ ৩: 10x + y + 18 = 10y + x ⇒ 9x − 9y + 18 = 0 ⇒ y = x + 2 ... (২)
ধাপ ৪: (২) কে (১) এ বসিয়ে 11x + 2 = 3x(x + 2) ⇒ 3x² − 5x − 2 = 0 ⇒ (x − 2)(3x + 1) = 0।
ধাপ ৫: x = 2 বা −1/3। অঙ্ক ঋণাত্মক বা ভগ্নাংশ হয় না, তাই x = 2, y = 4। সংখ্যা 24 ✔ (24 ÷ 8 = 3, 24 + 18 = 42 ✔)

📈 ল্যাব ১: দ্বিঘাত সমীকরণ ও প্যারাবোলা

👉 a, b, c স্লাইডারে বদলাও। নিশ্চায়ক D, মূল ও প্যারাবোলা একসাথে দেখো। প্যারাবোলা x-অক্ষকে যেখানে কাটে সেটিই মূল।

√ ল্যাব ২: বর্গমূলযুক্ত সমীকরণ ও অবান্তর মূল

👉 সমীকরণ √(px + q) = rx + s। স্লাইডার বদলাও। বর্গ করলে যে মূলগুলো আসে, সেগুলো আসলে ঠিক কিনা ল্যাব যাচাই করবে। নীল রেখা = বামপক্ষ, কমলা রেখা = ডানপক্ষ। ছেদবিন্দুই আসল মূল।

🔢 ল্যাব ৩: সূচক সমীকরণ

👉 মোড বেছে নাও। মোড ১: দুই পক্ষের ভিত্তি একই ভিত্তির ঘাত। মোড ২: p = aˣ ধরে দ্বিঘাত বানানো, আর গ্রাফে y = aˣ রেখা কোথায় y = p কে কাটে দেখো।

🧩 ল্যাব ৪: x² + y² = S, xy = P জোট

👉 S ও P বদলাও। (x+y)² = S + 2P এবং (x−y)² = S − 2P থেকে চার জোড়া সমাধান বের হবে। গ্রাফে বৃত্ত ও হাইপারবোলার ছেদবিন্দুই সমাধান। ডিফল্ট: বইয়ের উদাহরণ ২১ (S = 61, P = −30)।

🕐 ল্যাব ৫: ঘড়ির কাঁটা (অনুশীলনী ৫.৭ এর ১১ ও ১২)

👉 ঘণ্টার কাঁটা মিনিটে ০.৫° এবং মিনিটের কাঁটা মিনিটে ৬° ঘোরে। তাই মিনিটে ৫.৫° ব্যবধান বাড়ে। ১২ ঘণ্টায় কাঁটা দুটি কতবার বিপরীত (১৮০°) বা লম্ব (৯০°) হয়, তালিকা থেকে সময় চাপো।
